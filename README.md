# 弹幕发射器（Danmaku Overlay）

一个基于 **Electron** 的桌面弹幕悬浮窗。在看电视剧 / 电影（PotPlayer、VLC 等桌面播放器）时，一个**透明、无边框、始终置顶**的窗口覆盖在视频画面上方，实时渲染与剧情同步的弹幕，营造"边看边刷弹幕"的观影体验。

> 当前版本内置《五十公里桃花坞第5季》全季腾讯视频弹幕数据（117万条），可在设置面板「内置数据源」一键切换；同时提供通用弹幕采集脚本，支持采集任意腾讯视频节目。

## 功能特性

- 透明悬浮弹幕层：无边框、置顶、可拖拽对齐；进入「调整模式」显示醒目边界线与缩放手柄，平时完全透明无边界
- B 站风格弹幕：滚动 / 顶部 / 底部三种模式，黑色描边保证可读性
- 手动时间轴同步：播放 / 暂停、进度跳转、毫秒级偏移校准，解决弹幕与视频时间轴不对齐
- 点击穿透：一键切换，穿透时鼠标操作直达下方播放器
- 全局快捷键：观影过程中无需切换窗口即可控制
- 本地弹幕文件加载：支持加载 JSON 格式弹幕文件
- 参数可调：字号 / 速度 / 透明度 / 轨道数 / 密度 / 颜色模式，自动保存
- 智能防密集：屏幕同时可见弹幕数有动态上限，弹幕源再密集也不会糊成一团
- 字号随窗口缩放：窗口调整大小时弹幕字号按比例同步变化，始终对齐视频画面

## 分发给别人使用

给朋友 / 同事使用时，**对方不需要安装 Node.js**，直接给他打包好的压缩包即可：

**方式一：免安装压缩包（推荐）**

1. 运行打包命令生成 `release/DanmakuOverlay-v1.2.0-win32-x64.zip`
2. 把 zip 发给对方（约 106MB）
3. 对方**解压后双击 `DanmakuOverlay.exe`** 即可使用，无需安装任何环境
4. 首次运行如被杀毒软件提示，选择「仍要运行」即可（未签名应用属正常提示）

**方式二：开发者模式（需要 Node.js 18+）**

```bash
npm install
npm start
```

## 自行打包

项目已内置 `electron-builder` 配置，有 Node.js 环境即可自己打出新版本：

```bash
npm run pack       # 生成免安装便携版单文件 exe（dist/）
npm run dist       # 生成安装包 setup.exe（dist/）
```

> 国内网络下 electron-builder 若下载慢，命令前先执行：
> `$env:ELECTRON_BUILDER_BINARIES_MIRROR="https://npmmirror.com/mirrors/electron-builder-binaries/"`

## 安装与启动

启动后，弹幕悬浮窗默认铺满整个主屏。将其拖拽 / 拉伸对齐到你视频播放器的画面区域即可。

## 快速上手

1. 启动 `npm start`，窗口默认**自动开始播放**内置演示弹幕（覆盖 0~120 秒）
2. **对齐窗口**：鼠标移动到窗口内部显示控制条；按住控制条可拖动窗口位置；点击控制条里的**调整窗口**按钮进入调整模式，屏幕上会出现醒目的蓝色边界线和 8 个缩放手柄，拖动它们即可实时调整窗口大小，按 `Esc` 完成。平时窗口完全透明无边界，只在鼠标靠近边缘时短暂显示高亮边框提示可调整范围
3. 播放器播放视频时，按 `Ctrl+Alt+P` 同步开始弹幕；如弹幕与画面不同步，用 `-100 / +100` 按钮或设置面板里的「偏移校准」微调（精确到毫秒）
4. 对齐后按 `Ctrl+Alt+T` 开启**点击穿透**，鼠标即可正常操作下方播放器，弹幕照常播放
5. 换一集 / 换一个视频时，可用快进快退、进度条把弹幕时间轴调到对应位置

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Alt+D` | 显示 / 隐藏弹幕层 |
| `Ctrl+Alt+P` | 播放 / 暂停弹幕 |
| `Ctrl+Alt+→` | 快进 5 秒 |
| `Ctrl+Alt+←` | 快退 5 秒 |
| `Ctrl+Alt+T` | 切换点击穿透 |
| `Ctrl+Alt+Q` | 退出应用 |

## 控制条说明

鼠标移入窗口即显示底部控制条（移开后自动隐藏）：

- 播放 / 暂停
- 当前时间 / 总时长（总时长由弹幕数据最后一条的时间决定）
- 进度条：拖动跳转弹幕时间轴
- `-100 / +100`：偏移校准（弹幕提前 / 延后 100ms）
- 点击穿透开关
- 调整窗口大小（进入调整模式，显示边界线与缩放手柄）
- 设置面板
- 退出

**点击穿透**开启时，鼠标操作会穿透到下方播放器；把鼠标移到窗口最边缘（8px 内）可自动退出穿透，方便再次操作控制条。

## 设置参数

| 参数 | 说明 |
| --- | --- |
| 字号 | 基准字号（16~40px），窗口缩放时按宽度比例同步变化 |
| 滚动速度 | 滚动弹幕速度倍率（0.4x~2x） |
| 透明度 | 弹幕整体不透明度 |
| 轨道数 | 同时可用的滚动弹幕行数 |
| 弹幕密度 | 显示弹幕的比例，越低弹幕越稀疏 |
| 偏移校准 | 全局时间偏移（毫秒），解决弹幕与视频不同步 |
| 弹幕颜色 | 原色（数据自带）/ 纯白 / 多彩随机 |

所有设置自动保存，重启后保留。

## 弹幕数据文件

在设置面板点击「加载本地弹幕文件」可加载 JSON 格式弹幕，支持两种结构：

```json
[
  { "time": 0.5, "type": "scroll", "text": "来了来了" },
  { "time": 4.0, "type": "bottom", "text": "前方高能", "color": "#FF5C5C" }
]
```

或：

```json
{ "danmaku": [ ...同上... ] }
```

字段说明：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `time` | 是 | 弹幕出现的相对时间（秒，相对弹幕时间轴） |
| `type` | 否 | `scroll`（滚动，默认）/ `top`（顶部）/ `bottom`（底部） |
| `text` | 是 | 弹幕文字 |
| `color` | 否 | 弹幕颜色（十六进制），默认白色 |

示例文件见 [data/demo.json](data/demo.json)。

## 内置数据源（五十公里桃花坞 第5季）

项目已内置腾讯视频《五十公里桃花坞第5季》全季弹幕采集数据（约 **117 万条**，覆盖超前剧透/初见、第1~10期正片与加更等 49 个视频）。

打开设置面板 →「内置数据源」→ 点击任意一集即可加载对应弹幕，无需手动找文件。

> 注意：该数据集体积约 1.4GB，出于体积与版权考虑**未纳入本仓库**。克隆本项目后「内置数据源」为空，需使用下方「弹幕采集工具」自行采集，或加载自己的 JSON 弹幕文件。

数据存放于 `data/s5_mzc002005od4txd/`：

| 目录/文件 | 说明 |
| --- | --- |
| `episodes.json` | 剧集索引（vid / 标题） |
| `index.json` | 转换后剧集索引（文件名 / 弹幕条数） |
| `danmaku/*.json` | 精简弹幕文件，可直接加载到播放器 |
| `raw/*.json` | 原始弹幕数据（含 create_time、up_count 等元数据） |

## 弹幕采集工具

项目提供一套腾讯视频弹幕采集脚本（`scripts/`），采集其他节目/季的弹幕时使用：

```bash
# 1. 提取剧集列表（cid 为腾讯视频专辑 ID，见播放页 URL）
node scripts/fetch_episodes.js [cid] [首集vid]

# 2. 采集弹幕（串行扫描，每集约 30~60s，断点续采）
node scripts/collect_danmaku.js --vid=单集vid    # 采单集
node scripts/collect_danmaku.js                  # 采全部集

# 3. 转换为播放器可直接加载的精简格式
node scripts/convert_danmaku.js
```

采集依赖系统已安装的 Chrome / Edge（通过 playwright-core 驱动，无需额外下载浏览器）：

```bash
npm install playwright-core
```

弹幕接口：`https://dm.video.qq.com/barrage/segment/{vid}/t/v1/{start_ms}/{end_ms}`（每段最长 2 分钟）。采集的原始数据完整保留 `content`、`time_offset`、`create_time`、`up_count`、`user_vip_degree` 等字段，便于后续做弹幕分析。

> 说明：采集仅供个人学习研究，请遵守腾讯视频服务条款，控制请求频率。

## 技术说明

- **弹幕渲染**：Canvas 2D + `requestAnimationFrame`，文字离屏位图缓存（预绘制描边 + 填充，运行时逐帧 `drawImage`），对象池复用、离屏回收，弹幕量大时依旧丝滑
- **防密集控制**：密度概率丢弃 + 屏幕同时可见弹幕数动态上限（随轨道数 / 密度调节），双保险防止画面拥挤
- **字号自适应**：以首次铺满屏幕的宽度为基准，字号随窗口宽度等比缩放；调整窗口大小时屏幕上已有弹幕即时重排
- **独立弹幕时钟**：以 `performance.now()` 为基准，与播放器时间互不干扰，支持 play / pause / seek / offset 四种操作
- **点击穿透**：`setIgnoreMouseEvents(true, { forward: true })`，穿透时仍能感知鼠标位置，边缘热区自动退出
- **置顶级别**：`screen-saver` 级别置顶，确保覆盖在 PotPlayer / VLC 等播放器之上
- **数据接口解耦**：统一 `{ time, type, text, color }` 结构，新增数据源只需实现新的 loader 方法

## 后续扩展（预留接口）
