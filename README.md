# 弹幕发射器（Danmaku Overlay）

一个基于 **Electron** 的一站式弹幕观影工具，把「看视频 + 看弹幕」收进同一个窗口，无需浏览器与软件双开、无需手动对齐窗口、无需手动校准时间轴。

- **一体化模式（默认）**：应用内嵌浏览器直接打开影视网站看剧，弹幕层自动吸附到页面视频画面上，跟随播放 / 暂停 / 拖进度 / 换集 / 倍速**自动同步**；也支持直接打开本地视频文件叠加弹幕。内建腾讯视频弹幕**在线采集**面板，边看边采、即采即放。
- **外挂悬浮窗模式（兼容保留）**：原来的透明置顶弹幕悬浮窗能力完整保留，供 PotPlayer / VLC 等外部播放器场景继续使用，不做功能回退。

> **免责声明**：本项目仅供个人学习研究使用。工具不内置、不分发任何视频内容；本仓库不含任何平台的弹幕数据（仅含程序源码与示例数据），弹幕内容版权归原视频平台及发布用户所有。详见文末「免责声明」章节。

## 功能特性

### 一体化模式（默认启动）

- 一体化主窗口：自绘标题栏，工具栏内置「网页 / 本地」模式切换、地址栏与窗口控制
- **网页在线观影**：内嵌浏览器可访问任意站点，**自动探测页面主视频**（支持 iframe 内播放器与选集换源），弹幕层叠加在视频区域之上，随视频位置 / 尺寸 / 滚动 / 全屏自动跟随，不拦截鼠标，页面暂停 / 选集 / 全屏等操作零干扰
- **本地视频播放**：直接打开本地视频文件（mp4 / mkv / webm 等常见格式），弹幕叠加画面并自动同步
- **时间轴自动同步**：弹幕时钟绑定视频真实播放状态（播放 / 暂停 / 快进 / 拖进度 / 换集 / 倍速均自动跟随），另有毫秒级偏移微调作兜底
- **在线弹幕采集**：输入或自动识别腾讯视频 vid，后台分段拉取腾讯弹幕官方接口，实时进度、可取消，采集结果自动落盘并可直接加载播放（请求限速）
- 弹幕数据管理：内置《五十公里桃花坞 第5季》49 集索引一键切换；支持加载本地 JSON 弹幕文件 / 拖入视频或弹幕文件
- 参数全局共用并持久化：字号 / 速度 / 透明度 / 轨道数 / 密度 / 颜色模式、偏移校准

### 外挂悬浮窗模式（兼容保留）

- 透明悬浮弹幕层：无边框、置顶、可拖拽对齐；进入「调整模式」显示醒目边界线与缩放手柄，平时完全透明无边界
- B 站风格弹幕：滚动 / 顶部 / 底部三种模式，黑色描边保证可读性
- 手动时间轴同步：播放 / 暂停、进度跳转、毫秒级偏移校准
- 点击穿透：一键切换，穿透时鼠标操作直达下方播放器
- 智能防密集、字号随窗口缩放等比自适应，参数自动保存

## 快速上手（一体化模式）

1. `npm start` 启动进入一体化主窗口
2. **看网页**：顶栏保持在「网页」，地址栏输入影视站网址（起始页可填常用站点）打开剧集；页面检测到视频后自动就绪
3. **看本地**：切到「本地」，把视频文件拖进媒体区（或点「打开视频」），弹幕 canvas 自动叠加画面
4. 从右侧数据栏选择弹幕：点内置剧集、加载本地 JSON，或使用「在线采集」现采现放
5. 弹幕随即叠加并跟随视频进度同步；个别资源仍偏移时用 `-100 / +100ms` 微调
6. 需要给 PotPlayer / VLC 叠加弹幕时：打开设置抽屉 →「打开外挂悬浮窗」，按旧版方式对齐使用

## 外挂悬浮窗模式快速上手（原版用法）

1. 主窗口设置抽屉中点击「打开外挂悬浮窗」，透明悬浮窗默认铺满主屏
2. **对齐窗口**：鼠标移入窗口显示控制条，按住可拖动；「调整窗口」进入调整模式，拖动 8 个缩放手柄对齐到外部播放器画面，按 `Esc` 完成
3. 外部播放器开始播放时，按 `Ctrl+Alt+P` 同步弹幕；不同步用 ±100ms 或设置面板「偏移校准」微调
4. 对齐后按 `Ctrl+Alt+T` 开启点击穿透，鼠标可正常操作下方播放器
5. 换集 / 换视频时用快进快退与进度条把弹幕时间轴调到对应位置

## 设置参数

| 参数 | 说明 |
| --- | --- |
| 字号 | 基准字号（14~64px），网页 / 本地模式下随画面宽度等比缩放 |
| 滚动速度 | 滚动弹幕速度倍率（0.5x~2x） |
| 不透明度 | 弹幕整体不透明度 |
| 轨道数 | 同时可用的滚动弹幕行数 |
| 弹幕密度 | 显示弹幕的比例，越低弹幕越稀疏 |
| 颜色模式 | 原色（数据自带）/ 纯白 / 多彩随机 |
| 整体偏移 | 全局时间偏移（毫秒，±5000），解决个别资源时间轴不一致 |

所有设置自动保存，重启后保留。

## 弹幕数据文件

加载 / 拖入的 JSON 支持两种结构：

```json
[
  { "time": 0.5, "type": "scroll", "text": "来了来了" },
  { "time": 4.0, "type": "bottom", "text": "前方高能", "color": "#FF5C5C" }
]
```

或：

```json
{ "danmaku": [ ...同上... ] }
```

字段说明：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `time` | 是 | 弹幕出现的相对时间（秒，相对弹幕时间轴） |
| `type` | 否 | `scroll`（滚动，默认）/ `top`（顶部）/ `bottom`（底部） |
| `text` | 是 | 弹幕文字 |
| `color` | 否 | 弹幕颜色（十六进制），默认白色 |

示例文件见 [data/demo.json](data/demo.json)。

## 在线弹幕采集（腾讯视频）

一体化模式下可直接在右侧侧栏采集腾讯视频弹幕：

1. 把腾讯视频播放页网址粘贴到「网页」模式地址栏并打开，点侧栏「识别」自动提取 vid；或手动在输入框填入 vid（播放页 URL 中 `v0026…` 之类即 vid）
2. 点「开始采集」，后台按段（每段 2 分钟）串行拉取 `https://dm.video.qq.com/barrage/segment/{vid}/…`，实时显示进度与已采条数，可随时取消
3. 完成后自动转换并落盘到应用用户数据目录 `collected/`，可直接加载播放

采集脚本方式（`scripts/`，适合批量 / 其他节目）：

```bash
# 采集弹幕（串行扫描，每集约 30~60s，断点续采）
node scripts/collect_danmaku.js --vid=单集vid    # 采单集
node scripts/collect_danmaku.js                  # 采全部集
node scripts/convert_danmaku.js                  # 转换到 data/ 结构
```

> 说明：采集仅供个人学习研究，请遵守腾讯视频服务条款并控制请求频率（工具已内置 60ms 间隔限速）。

## 自行打包 / 分发给别人

**开发者模式（需要 Node.js 18+）**

```bash
npm install
npm start
```

**打包免安装版（对方无需安装 Node.js，解压 / 双击即用）**

```bash
npm run pack       # 生成 dist/DanmakuOverlay-*-portable.exe
npm run dist       # 生成安装包 setup.exe（dist/）
```

> 国内网络下 electron-builder 若下载慢，命令前先执行：

>
> 首次运行如被杀毒软件提示，选择「仍要运行」即可（未签名应用属正常提示）。

## 技术说明

- **网页模式不依赖窗口对齐**：桥脚本直接注入视频所在页面，弹幕层与视频同坐标系，随滚动 / 缩放 / 换源天然同步；Electron 可对跨域 iframe 执行注入，覆盖常见「播放器嵌 iframe」结构
- **弹幕引擎双驱动**：网页 / 本地模式使用「外部时钟源」绑定视频真实状态；legacy 悬浮窗沿用原自走时钟，互不干扰
- **状态事件驱动**：video 的 play / pause / seeked / ratechange / timeupdate 驱动弹幕时钟，播放状态约 250ms 节流回传，避免高频 IPC
- **安全边界**：第三方页面只运行在 webview guest 进程（独立持久会话、不启用 nodeIntegration、页面内容不进入应用渲染进程）；主界面保持 contextIsolation
- **性能**：Canvas2D 离屏位图缓存 + 对象池 + 轨道防追尾；弹幕数据按集一次解析排序，seek 定位二分查找
- **本地视频流**：通过自定义 `dm-video://` 协议 Range 拉流，支持拖进度条定位
- **数据接口解耦**：统一 `{ time, type, text, color }` 结构，本地 / 网页 / 采集结果同一套规范化输出
